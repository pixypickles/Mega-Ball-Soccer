# 大玉サッカー α v133

- 1対1／2対2／3対3を選択可能
- 青チーム：青と白の縦ストライプ
- ピンクチーム：ピンクとネイビーの太い横ボーダー
- ソックスの描き分けはありません
- D：ダッシュ / B：ジャンプ / A：アクション
- 特殊シュートによる場外吹っ飛び・復帰仕様を維持
- 操作キャラの頭上に水色の▽マーカーを全モードで表示

## v133 変更点

- ダッシュジャンプドロップキックを、頭を後ろ側に置き、胴体を横向きにして両脚を進行方向へ伸ばすポーズへ変更
- 通常の空中キック時に表示される技名を「JUMP KICK!」へ修正
- ジャンプ後にDで空中ダッシュしてからAを押した場合も、ダッシュジャンプドロップキックとして判定
- 上記入力でも、直接当てた相手は3秒、蹴ったボールに当たった相手は2秒の場外吹っ飛びになるよう統一

## v132 変更点

- 落下するボールで潰された選手は、起き上がるまでボールとの当たり判定を持たないように修正
- 複数人が落下地点に重なっている場合、同じ落下中に全員が同時に潰れるように修正
- 潰れた選手の上ではボールが跳ね返らず、地面に到達してから通常のバウンドをするように修正
