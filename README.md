# 大玉サッカー α v126

- 操作を3ボタンへ整理
- D：短距離ダッシュ（最も押しやすい上位置）
- B：ジャンプ（左下）
- A：アクション（右下）
- Aは状況に応じてキック／スライディング／ドロップキックへ自動切替
- ダッシュ中のAは、距離に応じてダッシュキック／ダッシュスライディング
- ダッシュジャンプ中のAはスーパードロップキック
- D→A、B→Aを連続入力しやすい三角配置

- キャラクター表示を80%へ縮小（当たり判定は維持）
- 画面比率に関係なく操作ボタンが下端で切れないよう縮小・右寄せ調整
